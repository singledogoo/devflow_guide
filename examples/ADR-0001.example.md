# ADR-0001（示例，不是生效决策）

- Status: Proposed
- Date: 待项目填写
- Decision owners: 待项目填写
- Context: 视频生产者与处理消费者速率不一致，需保证吞吐和队列行为有界。
- Alternatives: 单队列+拷贝 / 乒乓 Buffer / 有界环形 Buffer。
- Trade-offs: 延迟上限、内存占用、拷贝成本、丢帧策略、线程安全和 DMA Cache 一致性。
- Proposed decision: 经量测后再确定 Buffer 模型，现阶段**不作为已批准的架构契约**。
- Verification: Host 数据结构测试；指定板卡 DMA/Cache 实测；长稳/异常测试。
- Consequences: 一旦采纳，需更新接口、相关源代码和测试追踪。
